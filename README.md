# Frontend Technical Assessment

## Implementation Summary

### Completed Features

- [x] Drag & Drop functionality implemented (items can be dragged and placed correctly).
- [x] Blog List displays 10 blogs from the external API.
- [x] Blog filtering by Date, Reading Time, and Category dropdowns.
- [x] Blog filtering by Writing, Gadgets, Startups (second dropdown).
- [x] Keyword search implemented for blog titles.
- [x] Sticky navigation bar added and remains fixed on scroll.
- [x] Smooth scrolling implemented for navigation links.
- [x] Active section highlighting in navigation.
- [x] Navigation is mobile responsive.
- [x] Accessibility improvements (keyboard navigation, ARIA attributes, focus management).
- [x] Responsive design for multiple screen sizes (desktop, tablet, mobile).

### Pending Items

- None

### Technical Challenges

- Coding in plain JavaScript was a challenge. I've been using frameworks and libraries for a long time, so it was a bit of a challenge to code without them. It took me a while to find my bearings.

### AI Usage

- I used ChatGPT to assist me in debugging and refactoring my code.

## How to Run the Project

1. Clone the repository
   ```bash
   git clone https://github.com/emmyobonyo/frontend-technical-assessment.git
   cd frontend-technical-assessment
   git checkout main
   ```
2. Open the `index.html` file in a browser of your choice (You may need to run it with [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)).
